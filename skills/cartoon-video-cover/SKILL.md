# 卡通短视频封面

## 收到封面请求，先看用户有没有自己的角色

- 当前对话或内容项目已有用户确认的角色参考，直接复用，从本次需要的步骤开始。
- 还没有确认角色时，即使用户只说「帮我做封面」或直接发来视频，也先进入[角色创建](references/first-cover.md)。已有候选就请用户选定。还没有候选但已有授权素材或自述时，先生成角色三视角候选。需要素材时先提示「我们先做一个以后每条封面都能用的卡通形象。你可以发一张授权使用的照片，也可以用几句话描述你想要的样子。」收到其中一项就能开始。
- 首次做封面时，在用户选定形象后再进入封面制作。用户只要求做角色时，交角色参考即可。

## 1. 先定一个可以反复用的角色

从用户授权的参考素材或本人自述开始。用当前客户端的图片生成能力制作同一角色的**正面、四分之三侧面（约 45°）、纯侧面（约 90°）**。Codex 中用内置 ImageGen，豆包工作中用可接收参考图的图片生成能力。统一发型、脸、衣着、配饰、角色比例和画风。可用一张干净底色的设定图并排呈现，三视角保持同尺度。正面确认整体辨识度，四分之三侧面确认转头后的脸和头发，纯侧面确认鼻口和头部轮廓。

请用户挑定角色。已明确选择的直接采用，把参考图、固定特征和偏好配色存入用户的内容项目。已有角色就选最接近本次画面姿态的参考角度。如果现有角度无法支撑本次构图，可按原角色补画所缺角度，供用户确认后加入参考。带候选角色的试做标为待确认。

## 2. 从本条内容提炼两行字

先看成片、带时间戳字幕或用户简报，找出这条实际讲什么、观众能看到什么。两行分别写清主题与具体问题、结果或体验。短句优先，已确认文字逐字用。封面提到价格、数量、结果等关键事实时，回看实际原帧或重听原声，核对完整数字、单位和适用条件。自动字幕可能把连读词听成数字。原片不可用或证据不足时，改用可靠的说法，或请用户只确认会影响出图的关键事实。

## 3. 参考角色，分别生成两种构图

将已选角色图作为人物参考，提示词中写明必须保留的特征、本条相符的场景、动作和关键道具。配色和字效用使用者选定的方案。逐行给出准确中文字及层级，为字、脸和关键道具同时留空间。

- **竖版 3:4（1080×1440）**。按手机竖画布组织画面，给两行字留清楚的空间，脸、手上动作和关键道具避开边缘。
- **横版 4:3（1440×1080）**。独立安排字和人物，可以左右分区或调整前后层次。两版沿用同一角色、同一场景要点和同样的文字。

## 4. 看实际图再交付

逐张比对角色参考，逐字核对中文、数字和符号，检查文字对比度、人物辨识度及画面边界。把两版缩到约 240 px 宽各看一次，留意难读的字和贴边的脸、手、道具。有平台预览时按实际裁切再检查。错字可以局部重做。反复出错时生成无字画面，再添加可控文字层。

分别导出精确尺寸的 PNG 并重新读取像素。原图比例正确时等比缩放，比例不符时先调整构图或扩背景。保留已有确认版本，提供两张可打开的成品图和必要的待确认项。标题、话题等按当次要求加。当前环境无法用参考图出图时，交对应阶段的文案、构图和生图提示词，标为待出图稿。只能生成或预览图片时，报实际尺寸和仍待完成的导出步骤。
