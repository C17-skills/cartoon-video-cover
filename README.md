# 卡通短视频封面 Skill

陈十七制作。首次从一张授权参考图或几句自述开始，先选定自己的卡通角色，再根据每条视频做竖版 3:4（1080×1440）和横版 4:3（1440×1080）封面。已有确认角色时直接沿用。

## Codex

把[这个 Skill 链接](https://github.com/C17-skills/cartoon-video-cover/tree/main/skills/cartoon-video-cover)发给 Codex，说「帮我安装这个 Skill」。也可以在项目目录运行下面的安装命令。

```bash
npx -y skills add C17-skills/cartoon-video-cover --skill cartoon-video-cover --agent codex --copy --yes
```

安装后输入「用 `$cartoon-video-cover` 帮我做这条视频的封面」，附上视频、字幕或简报。

## 豆包工作电脑版

1. [下载豆包工作导入包](https://raw.githubusercontent.com/C17-skills/cartoon-video-cover/main/downloads/cartoon-video-cover-doubao.zip)。
2. 在豆包工作的技能页面选择「上传技能」，选中下载的 ZIP。
3. 在对话中选中该 Skill，说「帮我做这条视频的横竖封面」。

首次使用会先提示你做自己的形象。参考图默认有正面、四分之三侧面（约 45°）和纯侧面（约 90°）。图片生成取决于客户端可用的生图能力。[豆包工作技能说明](https://www.feishu.cn/content/article/7677519271848610746)
